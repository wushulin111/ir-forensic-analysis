# 攻击路径复盘与因果链推理 v1.0

> 借鉴 Solar 应急响应团队「攻击路径复盘方法论」：从初始访问到最终影响，
> 每条时间线条目之间必须建立强因果关系（Cause → Effect）。
> v3.0 新增，与 SKILL.md 分析流程配合使用。

---

## 推理框架

### 攻击链通用模型

```
初始访问 → 执行 → 持久化 → 提权 → 防御规避 → 凭据窃取 → 横向移动 → C2 → 数据外泄/影响
     ↓        ↓        ↓        ↓        ↓            ↓          ↓        ↓         ↓
  漏洞/钓鱼  白加黑   注册表   UAC绕过  杀软关闭     Mimikatz   PsExec   端口转发   加密/窃取
  RDP暴破   宏代码   计划任务 Token   ntdll重映射  LSASS转储  WMI远程  DNS隧道    勒索信
  供应链    PowerShell WMI   SUID    进程注入     SAM读取    SSH      反向Shell  数据外传
  NAS漏洞  Webshell  服务劫持 sudo    驱动加载     票据传递   WinRM   C2端口    虚拟机加密
```

### 因果链等级

| 等级 | 符号 | 定义 | 示例 |
|------|------|------|------|
| **强因果** | ❱ | 有时间关联 + 进程/网络/文件证据链 | `svchost.exe 14:32:15发起出站8880→C2 ❱ 14:32:18注入explorer.exe` |
| **弱因果** | → | 有时间关联但缺中间证据 | `RDP登录 03:00 → 03:15卷影删除` |
| **关联** | ➔ | 仅特征匹配，无直接证据 | `.mallox后缀文件出现 ➔ 疑似mallox勒索` |
| **独立** | ● | 无时间关联，单独评估 | `SMB 445扫描 04/20 ● SSH爆破 04/22` |

## 必须遵循的推理规则

### 规则1：同一时间窗口优先串联

同一分钟内的进程创建+网络连接优先视为同一链路。不超过5分钟的事件窗口视为"关联操作"。

```
14:32:10 svchost.exe异常子进程创建 → 14:32:15 出站TCP 8880连接 → 14:32:18 explorer.exe被注入
→ 结论：同一攻击链，C2通信建立后立即进行进程注入
```

### 规则2：进程父子关系优先于时间顺序

父进程创建子进程时，以父子关系为准，即使时间戳有偏移。

```
cmd.exe(父) → powershell.exe(子) → certutil.exe(孙)
→ 即使certutil执行时间在powershell之前记录，仍按父子链推理
```

### 规则3：逆向溯源法

发现影响事件(Impact)后，必须逆向追溯攻击路径：

```
发现加密文件 → 谁加密的(进程) → 加密进程从哪来(父进程/下载源) → 初始访问入口
                          ↓
              是否有C2通信 → C2从哪来 → 是否有持久化维持 → 入侵起点
```

**强制要求**：每个 Critical/High 发现必须执行至少3层逆向溯源。

### 规则4：多攻击链分离

如果两个高危事件之间无时间/进程/网络关联，分别报告为独立攻击链。

```
攻击链A：Webshell → 进程注入 → C2通信
攻击链B：RDP暴破 → 勒索加密
→ 即使在同一台机器上，若证据链不连通，分别报告
```

### 规则5：空白窗口标注

时间线上超过4小时无事件但后续有C2通信时：

```
[14:00 Webshell上传] --- [18:30 C2通信建立] --- [19:00 横向移动]
                   ↑ 空白窗口 ↑
→ 标注："4.5小时空白窗口，可能有未采集的Event ID 4688/1进程创建事件，建议补充安全日志"
```

### 规则6：攻击链完整性评分

| 覆盖阶段数 | 完整性 | 说明 |
|-----------|--------|------|
| ≥7阶段 | High | 从初始访问到影响基本完整 |
| 4-6阶段 | Medium | 缺少部分中间阶段 |
| 2-3阶段 | Low | 只有头尾，中间环节推测 |
| 1阶段 | Minimal | 单点发现，无法构建链路 |

### 规则7：Dwell Time 评估

**Dwell Time = 首次入侵时间 → 首次发现/加密时间**

| Dwell Time | 风险评估 | 说明 |
|-----------|----------|------|
| <1小时 | 快速攻击 | 自动化勒索/已知工具链 |
| 1-24小时 | 短期驻留 | 有预谋但行动迅速 |
| 1-7天 | 中期驻留 | 可能已横向移动+数据窃取 |
| >7天 | 长期驻留 | APT/深度渗透，需全量排查 |

### 规则8：第三方运维入口专项标注

如果初始访问来自第三方VPN/IP段/IPMI口/供应链软件：

```
⚠ 第三方运维风险入口：
- 入侵路径：第三方运维IP 203.xx.xx.xx → RDP 3389 → 内网横向
- 建议：审计第三方运维账号权限、IP白名单、会话录制
```

## 勒索病毒攻击链专用推理

### 通用勒索攻击链

```
初始访问(RDP暴破/漏洞/钓鱼) → 执行(Payload落地) → 防御规避(杀软关闭/卷影删除)
→ 发现(文件枚举/数据库停止) → 加密(AES/RSA批量加密) → 勒索(赎金信+数据泄露威胁)
```

### Solar案例推理模式

| 入口 | 家族 | 攻击链 |
|------|------|--------|
| RDP暴破 | Phobos | RDP弱口令→登录→部署后门→卷影删除→AES+RSA加密→勒索信 |
| NAS漏洞 | mallox | NAS Web漏洞→Webshell→内网代理→横向到服务器→加密→勒索信 |
| 用友NC | babyk | 用友NC漏洞→内网渗透工具→横向数十台→批量虚拟机加密→勒索信 |
| ESXi SSH | BEAST | SSH暴破→登录ESXi→批量VM关机→加密.vmdk/.vmx→勒索信 |
| 银狐关联 | .sorry | 银狐木马→C2建立→远控→投放勒索→加密→勒索信 |

## 供应链入侵专用推理

### 第三方运维盲区检查清单

1. 检查 RDP/SSH 来源IP是否包含第三方运维IP段
2. 检查 VPN 账号是否有共享/通用密码
3. 检查 IPMI/BMC 带外管理口是否暴露
4. 检查防火墙规则是否有过于宽泛的放行规则
5. 检查非工作时间的管理端口访问记录
6. 检查供应链软件（用友/金蝶/OA等）是否有已知漏洞
7. 检查NAS设备的Web管理面板是否暴露

### 供应链攻击链标注

```markdown
| 时间 | 事件 | 因果 | 入口类型 |

| Day1 22:05 | Webshell上传 | ❱ 因:NC漏洞允许文件上传 | 供应链漏洞 |
```
